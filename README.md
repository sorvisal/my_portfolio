## 🌐 Overview

**My Portfolio** is a personal developer portfolio built to showcase my technical expertise, professional background, and software development projects.

I am **Sor Visal**, a Backend Developer and aspiring DevOps Engineer passionate about building reliable backend applications, automating deployment workflows, and managing modern infrastructure.

The portfolio highlights my experience with backend development, database management, Linux administration, containerization, and CI/CD automation.

### 🎯 Portfolio Goals

- Showcase my professional profile and technical expertise.
- Present real-world software development projects.
- Highlight my professional experience and education.
- Demonstrate my backend and DevOps engineering journey.
- Provide an easy way for recruiters and developers to connect with me.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### 1. Prerequisites

Make sure you have installed:

- Node.js (LTS)
- npm
- Git

### 2. Clone the Repository

```bash
git clone https://github.com/sorvisal/my-portfolio.git
```

### 3. Navigate to the Project

```bash
cd my-portfolio
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start Development Server

```bash
npm run dev
```

### 6. Open in Browser

Visit:

```text
http://localhost:3000
```

The application will automatically reload when you modify the source code.

## 🏗️ Build & Deployment

### Production Build

```bash
npm run build
```

### Start Production Server

```bash
npm run start
```

### Deployment

The portfolio can be deployed using [Vercel](https://vercel.com/), the platform built by the creators of Next.js.
